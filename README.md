# ControlGastos (Android)

App Android (Kotlin, Views XML + View Binding) que usa la libreria `gastos-core` (proyecto Maven aparte).

- Tiene 2 categorías para elegir que son los siguientes:

* GASTOS - Que se desglosa en las siguientes:
   Trasporte 
   Comida
   Ropa 
   Diario
   Comunicación
   Belleza Alquiler 
   Hogar
   Niños
